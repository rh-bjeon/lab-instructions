# RAG 201

> 기초는 갖추었으니 — 이제 RAG를 프로덕션으로 가져가 봅시다. 이 섹션은 모든 것을 하나로 엮어 완전히 자동화되고, 평가되며, GitOps로 관리되는 지식 시스템을 만듭니다.

RAG 101을 기반으로, pipeline을 end-to-end로 production화해보겠습니다:

* **Prepare Prod** — production 환경과 인프라 설정하기
* **RAG Pipelines** — Kubeflow로 문서 수집(ingestion)과 vector store 채우기를 자동화하기
* **Canopy with RAG** — retrieval을 AI assistant에 통합해 여러분의 문서를 바탕으로 답변하도록 만들기
* **RAG Evals** — RAG의 특성에 맞게 조정된 LLM-as-judge scorer로 검색 품질을 측정하기
* **Pipeline of Pipelines** — 모든 변경마다 자동으로 eval을 실행하는 Tekton 트리거로 루프를 완성하기
