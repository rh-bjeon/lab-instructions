# RAG 101

> RAG 시스템을 만들기 전에, embeddings와 vector search부터 문서 chunking과 retrieval pipeline에 이르기까지, 실제로 내부에서 무슨 일이 일어나는지 이해해야 합니다.

이 섹션에서는 핵심 구성 요소들에 대한 개념적 기초와 실습 경험을 쌓게 됩니다:

* **RAG 소개** — retrieval-augmented generation이 무엇이며 왜 중요한지
* **RAG 이해하기** — embeddings, 유사도 검색, 컨텍스트 주입이 어떻게 함께 동작하는지
* **Vector Stores & Milvus** — production급 vector database를 배포하고 쿼리하는 방법
* **Docling을 활용한 문서 인텔리전스** — 복잡한 PDF를 처리하고 수집(ingestion)을 위해 구조화된 콘텐츠를 추출하는 방법
