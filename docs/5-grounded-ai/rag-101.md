# RAG 101

> RAG 시스템을 만들기 전에 임베딩과 벡터 검색, 문서 청킹, 검색 파이프라인이 내부에서 어떻게 동작하는지 이해해야 합니다.

이 섹션에서는 핵심 구성 요소의 개념을 배우고 직접 실습합니다.

* **RAG 소개** — 검색 증강 생성이 무엇이고 왜 필요한지
* **RAG 이해하기** — 임베딩과 유사도 검색, 컨텍스트 주입이 함께 동작하는 방식
* **벡터 저장소와 Milvus** — 운영 환경에서 사용할 벡터 데이터베이스를 배포하고 쿼리하는 방법
* **Docling을 활용한 문서 인텔리전스** — 복잡한 PDF를 처리하고 수집에 필요한 구조화된 콘텐츠를 추출하는 방법
