# 모듈 5 - 도서관

> AI에 기억하는 방법을 가르치는 일은 도서관 이용증을 건네는 것과 같습니다. 아무리 뛰어난 모델도 외부 지식에 접근하지 못하면 학습할 때 익힌 정보에만 의존합니다. RAG를 사용하면 AI가 제공된 문서를 검색하고, 그 내용을 바탕으로 답변을 만들 수 있습니다. 📚

# 🧑‍🍳 모듈 소개

이 모듈에서는 일반적인 AI 대화를 넘어, 조직의 문서와 지식 기반을 활용하는 지능형 시스템을 구축합니다. 검색 증강 생성(Retrieval-Augmented Generation, RAG)이 정적인 AI 모델을 강의 자료와 기관 문서, 학생 제출물을 참조하는 동적인 어시스턴트로 바꾸는 과정을 살펴봅니다.

RDU는 교수자와 학생이 방대한 학술 자료를 편리하게 활용할 수 있도록 Canopy를 개발하고 있습니다. RAG는 문서를 검색 가능한 지식으로 변환하고, 사용자의 질문과 관련된 내용을 찾아 AI 응답의 정확도를 높입니다.

# 🔮 학습 성과

* RAG의 개념과 AI가 강의 자료를 활용하도록 만드는 방법을 이해합니다
* Open GenAI Stack(OGX)으로 벡터 데이터베이스를 배포하고 RAG 시스템을 구축합니다
* Docling을 사용해 복잡한 PDF와 문서를 처리합니다
* 출처를 제시하는 지능형 교육용 어시스턴트를 만듭니다
* GitOps로 운영 환경에 사용할 수 있는 지식 시스템을 배포합니다

# 🔨 이 모듈에서 사용하는 도구들

* **[Open GenAI Stack, 이전 이름 Llama Stack](https://ogx-ai.github.io/)** - 생성형 AI 애플리케이션을 구축하기 위한 오픈소스 프레임워크
* **OGX RAG API**: 검색 증강 애플리케이션을 구축하기 위한 3계층 아키텍처
* **Milvus 벡터 데이터베이스**: 의미 기반 검색과 정보 검색을 위한 고성능 벡터 데이터베이스
* **Docling**: PDF 분석과 콘텐츠 추출을 위한 문서 처리 파이프라인
* **RAG 도구**: 문서 수집(ingestion), 청킹(chunking), 쿼리 기능
* **Vector IO와 KeyValue IO**: 서로 다른 데이터 유형을 처리하는 저수준 스토리지 인터페이스
* **OpenShift와 Helm 차트**: 개발 및 운영 환경에 RAG 인프라를 배포하는 도구
* **확장된 Canopy**: 문서를 인식하고 지식으로 활용하는 교육용 AI 어시스턴트
