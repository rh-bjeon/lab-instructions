# 모듈 10 - 피트니스 프로그램

> 70B 모델의 성능은 뛰어나지만 하루 500달러의 GPU 비용이 들고, 학생들은 응답을 받을 때마다 10초씩 기다려야 합니다. 이제 모델의 체급을 줄일 시간입니다. 🏋️

# 🧑‍🍳 모듈 소개

이 모듈에서는 모델의 품질을 최대한 유지하면서 크기와 비용을 줄이고 속도를 높이는 방법을 다룹니다. 양자화(quantization)로 LLM을 압축하고 품질과 성능을 평가한 뒤 GitOps 파이프라인으로 배포합니다.

**핵심 질문:** *사용자 경험을 해치지 않으면서 모델을 얼마나 압축할 수 있을까?*

# 🔮 학습 목표

* **용어 이해하기** — FP16, INT8, INT4, W8A16의 의미와 적절한 사용 시점 알아보기
* **기법 선택하기** — GPTQ, AWQ, SmoothQuant 가운데 작업에 맞는 도구 고르기
* **모델 압축하기** — `llm-compressor`로 운영 환경에 사용할 모델 압축하기
* **품질 검증하기** — 양자화된 모델을 평가해 품질 저하 확인하기
* **배포하기** — GenAIOps 파이프라인으로 최적화한 모델 배포하기

# 🔨 이 모듈에서 사용하는 도구

| 도구 | 역할 |
|------|------|
| **llm-compressor** | 모델을 실제로 압축하는 vLLM 양자화 툴킷 |
| **lm-evaluation-harness** | 표준 벤치마크로 압축 전후의 품질을 비교하는 도구 |
| **GuideLLM** | 지연 시간, 처리량, 첫 토큰 생성 시간을 측정하는 성능 테스트 도구 |
| **vLLM/KServe** | 압축한 모델을 운영 환경에 서빙하는 플랫폼 |
| **Argo CD** | 모델을 테스트 환경에서 운영 환경으로 승격하는 GitOps 배포 도구 |
