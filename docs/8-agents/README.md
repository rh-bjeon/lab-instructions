# 모듈 8 - 자율 시스템 101

> LLM만으로는 요리법을 설명할 뿐 직접 요리하지는 못하는 셰프와 같습니다. 도구와 자율성을 더하면 정보를 검색하고 일정을 잡고 계산하며 실제 작업까지 수행할 수 있습니다. AI 에이전트의 세계에 오신 것을 환영합니다!

# 🧑‍🍳 모듈 소개

이 모듈에서는 텍스트만 생성하는 LLM을 넘어 추론하고 계획하고 행동하는 자율 에이전트를 구축합니다. 도구가 LLM의 능력을 어떻게 확장하는지, MCP 서버가 확장 가능한 도구 생태계를 어떻게 제공하는지, ReAct와 같은 에이전틱 워크플로가 어떻게 여러 단계의 추론을 수행하는지 배웁니다.

RDU는 Canopy를 단순한 챗봇에서 실제 업무를 돕는 학생 어시스턴트로 발전시키고 있습니다. Canopy는 지식 기반을 검색하고 교수자와의 면담을 예약하며 학생이 학업 과정을 탐색하도록 돕습니다. 모듈을 마치면 RAG와 도구 호출, 의사결정을 결합한 에이전트를 배포하게 됩니다.

# 🔮 학습 목표

* 도구가 텍스트 생성을 넘어 LLM의 능력을 확장하는 방식을 이해합니다.
* 확장 가능한 도구 모음을 제공하는 MCP(Model Context Protocol) 서버를 배포하고 사용합니다.
* 자율 에이전트를 구축하는 ReAct(Reasoning and Acting) 패턴을 배웁니다.
* Llama Stack과 통합된 LangGraph로 에이전트를 구축합니다.
* GitOps 파이프라인으로 에이전트 기능을 테스트 및 운영 환경에 배포합니다.
* RAG 지식과 도구 기반 행동을 결합한 지능형 어시스턴트를 만듭니다.

# 🔨 이 모듈에서 사용하는 도구

* **LLM 도구**: LLM이 계산기, 데이터베이스, API 같은 외부 서비스와 상호작용하는 JSON 기반 인터페이스
* **MCP 서버**: LLM이 사용할 수 있는 도구 모음을 제공하는 표준 서버
* **ReAct 프레임워크**: LLM이 반복 루프 안에서 추론하고 행동하며 결과를 관찰하는 패턴
* **LangGraph**: 복잡한 에이전틱 워크플로를 구축하는 운영 등급 그래프 기반 프레임워크
* **Llama Stack Agent API**: AI 에이전트를 구축하고 오케스트레이션하는 통합 계층
* **Calendar MCP Server**: 일정과 캘린더 관리 기능을 제공하는 예제 도구 서버
* **OpenShift와 Helm 차트**: 개발 및 운영 환경에 에이전트 인프라와 MCP 서버를 배포하는 도구
