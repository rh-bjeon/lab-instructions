# 모듈 7 - 명예 규칙

> 신뢰할 수 있는 AI를 만들려면 명확한 경계가 필요합니다. 교사가 교실의 규칙을 정하듯 가드레일은 AI가 유용하고 안전하며 정직하게 행동하도록 지켜줍니다. 🛡️

# 🧑‍🍳 모듈 소개

이 모듈에서는 AI 애플리케이션에 안전 가드레일을 적용하는 방법을 다룹니다. 교육용 AI 어시스턴트를 오용으로부터 보호하고 책임 있는 상호작용을 보장하며, 프롬프트 엔지니어링만으로는 막기 어려운 위협에 대응하는 다층 보안을 구축합니다. 시스템 프롬프트부터 전문 탐지 시스템까지 살펴보며 AI의 유용성과 안전성, 규정 준수 사이에서 균형을 잡는 방법을 배웁니다.

RDU는 Canopy를 신뢰할 수 있는 교육 도구로 만들고자 합니다. 가드레일은 강력한 언어 모델을 학생과 교수자가 학업 윤리와 편향, 유해 콘텐츠 문제를 관리하며 사용할 수 있는 책임 있는 어시스턴트로 바꾸는 핵심 요소입니다.

# 🔮 학습 목표

* 가드레일의 개념과 운영 AI 애플리케이션에 필요한 이유를 이해합니다.
* 프롬프트 수준 가드레일의 한계와 외부 정책 적용이 필요한 이유를 배웁니다.
* Helm 차트로 NeMo Guardrails를 배포하고 다층 안전 정책을 구성합니다.
* 여러 탐지기가 서로 다른 유형의 유해 콘텐츠를 찾는 방식을 확인합니다.
* 안전 조치를 우회하려는 공격을 테스트하고 AI 애플리케이션의 방어를 강화합니다.

# 🔨 이 모듈에서 사용하는 도구

* **NeMo Guardrails**: Colang으로 정의한 안전 규칙을 적용하는 외부 정책 계층
* **정규식 규칙**: 특정 콘텐츠 패턴을 차단하거나 표시하는 패턴 기반 필터
* **HAP Detector**: 혐오 발언, 모욕, 비속어를 탐지하는 분류기(Granite Guardian)
* **Prompt Injection Detector**: AI 동작을 조작하려는 시도를 식별하는 보안 계층(DeBERTa)
* **Language Detector**: 응답 언어를 영어로 제한하는 탐지기(Lingua)
* **Spikee**: 가드레일을 벤치마킹하는 오픈 소스 프롬프트 인젝션 자동 테스트 도구
* **OpenShift와 Helm 차트**: 개발 및 운영 환경에 NeMo Guardrails 인프라를 배포하는 도구
